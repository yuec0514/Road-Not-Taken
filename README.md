未行之路｜开局准备独立演示（基于 0.6.0）

打开方式（Windows 一键本地试玩）
1. 先将整个 ZIP 解压到一个文件夹。
2. 双击“双击启动试玩.cmd”。
3. 启动器使用 Windows 自带的 PowerShell，自动启动本地服务，并打开默认浏览器。
   无需安装 Node.js、Python 或依赖；无需联网，不需要管理员权限。
4. 请保持启动窗口打开，关闭窗口或按 Ctrl+C 即停止试玩。
   如未自动打开浏览器，请复制窗口中的 http://127.0.0.1:端口/ 地址到 Chrome 或 Edge。

默认从 5186 端口开始，端口被其他程序占用时自动尝试下一个。
再次双击会尝试打开这份演示已经启动的网址。
服务只绑定 127.0.0.1，仅供此电脑访问。
请勿在压缩软件内直接运行，或只发送启动文件；整个文件夹需一起保留。
不要在聊天软件的文件预览里打开 HTML。原“打开演示.html”保留为离线文件备用入口。

运行环境
Windows 10 / 11 自带的 Windows PowerShell 5.1，以及支持 WebGL 的 Chrome 或 Edge。
macOS / Linux 用户仍可使用现有 HTML 备用入口，或自行启动静态文件服务。

包含流程
加载 → 标题 → 生活处境 → 生活重心（预设 / 自定义 9 点）→ 旅人形象。
点击“开始生活”显示准备完成，可返回调整或返回标题。
保留紫色云间浮岛背景、旅行票券、字体、三维旅人实时预览、外部条件与返回操作。
“继续旅程”只恢复此演示的准备草稿；“旅程收藏”为未完成旅程的空状态。
浏览器允许本地存储时才保存草稿；存储被禁用也可走完整个流程。
不含后续河湾生活、关键选择、季节转场或结局玩法。

给负责开发的组员
完整源码在 src，静态原图和字体在 public，已构建成品在 dist。
安装 Node.js 22 或更新版本后，可双击“启动开发.cmd”。
或在本目录依次运行：npm ci、npm run dev。
重新生成成品：npm run build。成品仍可直接用本地文件方式打开。
请保留依赖锁定文件 package-lock.json 与字体 / Three.js 授权。

主要文件
tools/serve-demo.ps1：使用 Windows 自带组件的本地静态服务；仅提供 dist 成品。
双击启动试玩.cmd：一键运行本地服务并打开浏览器。
src/app.ts：标题、三步准备、预设与点数分配、独立流程结束。
src/portrait.ts：独立三维预览，不依赖地图、行走或季节系统。
src/character.ts：沿用原版程序化角色。
src/model.ts：仅保留准备阶段数据、角色所需类型和外部条件生成。
src/journey.css、interface.css、storybook.css：保留原版样式，方便与主项目接回。
草稿：road-entry-draft-v1；设置：road-entry-settings-v1，与原游戏记录分开。
